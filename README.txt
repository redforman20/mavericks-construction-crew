Maverick Construction Crew v7 — voice selection + speed control.

Parent Settings includes available Safari English voices, automatic male voice preference (best effort), 1.00x default speaking speed, Test Voice and Refresh Voices. The default preference is automatic male. Safari does not provide reliable voice gender metadata.

Upload index.html, sw.js, manifest.webmanifest, icon-192.png, and icon-512.png to the ROOT of your existing GitHub repository, replacing the old files. Commit the changes and reload the game. The website URL stays the same.

Existing progress is preserved using the same localStorage key (maverick-construction-v1). On an iPhone/iPad, voices may load after the page opens; use Refresh Voices. Speech playback requires user interaction and may depend on Safari voice support.
